Reading Data and Important Tools In

To begin with, we’ll need to use the Pandas library to read in and polish up our data. After that, we’ll be using the express package from the plotly library, which is how we will plot out the pandas dataframe. Here we’re importing our necessary items, and then reading our data in through the read_csv command, passing in this publicly available url of the Palmer dataset. Let’s see what our data looks like with head.

import pandas as pd

Cleaning Up the Data

Now that the set is on our machine, we need to make sure it’s perfectly usable. For one, some values in the ‘body mass (g)’ column, are not in numerical format (see index entry 3). As such, we will purge them through the dropna() command.

Since we are separating our data up by species type, we need to make sure that column is also perfectly usable. The entries in the species column are stated as “Adelie Penguin.” The fact they’re penguins is pretty redundant, so let’s only include the species name in that column. To do so, we’ll reassign that column by splitting up the string entry with str.split(), and then only grabbing the 0th index of the now 2 strings.

We also are only using a few columns, so we might as well just throw out the excess. Let’s make a list of all of the columns we want (just species and mass), and then use that as a mask over our set.

Just to make sure our data is working properly, let’s get the head of our modified set and ensure everything is in order.

penguins = penguins.dropna(subset = ["Body Mass (g)"]) # removing non-number entries
penguins["Species"] = penguins["Species"].str.split().str.get(0) # splits species title, grabs first one

cols = ["Species", "Body Mass (g)"]
penguins = penguins[cols]

Plotting the Data

Now that the data is usable, let’s construct our simple histogram. We’ll be using the histogram function from Plotly Express. Following along with the documentation, we can find which arguments we need to set. Using the penguin dataframe, we’re charting the Body Mass column as our x-axis. To differentiate between the types of penguins, we’ll assign the different Species values as different colors. For a better visual, we will set the opacity to 0.5, and split our mass ranges into 30 bins. One of the barmode settings is stack, which will make apparent how many of each species are in one mass bin. This will eliminate overlap. We need our title, and to set the dimensions of our figure.

To clean up the chart one more time, we’re eliminating the margins everywhere but on the top (so the title isn’t cut off).

Our chart is now ready, and we can see that gentoo penguins are a lot bigger than the other two species, while chinstrap and adelie penguins follow similar distributions.

# Documentation found on https://plotly.github.io/plotly.py-docs/generated/plotly.express.histogram.html

fig = px.histogram(penguins, 
                   x = "Body Mass (g)", 
                   color = "Species",
                   opacity = 0.5, 
                   nbins = 30, 
                   barmode='stack',
                   width = 600,
                   height = 300, title = "Body Mass Distribution of Penguins by Species")

# reduce whitespace
fig.update_layout(margin={"r":0,"t":40, "l":0,"b":0})
# show the plot
fig.show()
